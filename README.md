# Лабораторная работа: Хеш-таблицы

## Цель
Научиться реализовывать хеш-таблицы, метод resize и хеш-функции для строк.

## Файлы проекта
- `hash_table.py` — класс `HashTable`.
- `string_hash.py` — хеш-функция для строк.
- `string_dict.py` — словарь на её основе.
- `demo.py` — демонстрация.

## 1. Класс HashTable

Реализованы методы `insert`, `search`, `delete`, `resize`.
Разрешение коллизий — **метод цепочек** (chaining): каждая ячейка
хранит список пар `(ключ, значение)`.

Индекс вычисляется как `hash(key) % size`.

### insert
- Если ключ уже есть — обновляем значение.
- Иначе добавляем в корзину и увеличиваем `count`.
- Если `count / size > 2/3` — вызываем `resize(size * 2)`.

### search
- Идём в корзину по индексу, ищем совпадение ключа.
- Возвращаем значение или `None`.

### delete
- Ищем ключ в корзине, удаляем пару.
- Возвращаем `True`, если удалось удалить, `False` — если ключа не было.

### resize
- Создаём новую таблицу размера `new_size`.
- Перебираем все старые корзины и заново вставляем элементы.
- Это называется rehash.

## 2. Тест resize

Начальный размер 5, добавляем 10 ключей. По мере роста таблица
автоматически увеличивается: **5 → 10 → 20**.
После добавления 10 элементов: `size = 20`, `count = 10`.
Коэффициент заполнения — 0.5, что ниже порога 2/3.

## 3. Хеш-функция для строки

```python
def string_hash(s):
    return sum(ord(ch) for ch in s)
```

Складываем ASCII-коды всех символов. Примеры:
- `string_hash("abc")` = 97 + 98 + 99 = **294**
- `string_hash("Hello")` = **500**
- `string_hash("")` = **0**

Недостаток: перестановки символов дают одинаковый хеш
(`"ab"` и `"ba"` → 195). Для учебной задачи это допустимо.

## 4. Словарь на основе хеш-функции

Класс `StringDictionary` хранит пары `(строка, её_хеш)`.
- `add(key)` — добавляет ключ, значение = `string_hash(key)`.
- `get(key)` — возвращает хеш по ключу или `None`.

Внутренняя структура — хеш-таблица с chaining.

## Вывод

Хеш-таблица даёт O(1) в среднем на вставку, поиск и удаление.
При большом коэффициенте заполнения растёт число коллизий,
поэтому нужно вовремя делать resize. Метод цепочек — простой и
надёжный способ разрешения коллизий. Простая хеш-функция
(сумма ASCII) подходит для учебных примеров, но даёт много коллизий;
на практике используют полиномиальные хеши или встроенный `hash()`.
